# Advanced Network Routing & DPI Evasion 🌐🛡️

Набор конфигураций и скриптов для глубокой маршрутизации трафика (L4/L7), микросегментации сетей и криптографического обхода систем глубокого анализа пакетов (DPI).

## 🎯 Реализованные решения

### 1. eBPF Transparent Proxy (`dae`)
Использование технологии eBPF на уровне ядра Linux для обработки трафика с нулевой потерей производительности (Zero-copy).
* Маршрутизация на основе `geosite` и `geoip` баз.
* Вывод ресурсоемкого P2P/IoT трафика в `DIRECT` (минуя userspace-прокси) для разгрузки CPU маршрутизатора.

### 2. VLESS-Reality & Traffic Obfuscation
* Настройка `Xray-core` для маскировки туннельного трафика под легитимные HTTPS-запросы к крупным корпоративным доменам (например, `dl.google.com`).
* Защита от активного пробинга (Active Probing) со стороны провайдера.

### 3. Микросегментация через `nftables`
* Изоляция недоверенных узлов сети. Пример правила для запрета доступа гостевого VPN-контейнера к локальной сети:
```bash
# Разрешаем выход только в интернет, блокируем Management LAN
nft insert rule inet fw4 forward ip saddr 192.168.1.105 ip daddr 192.168.1.0/24 counter drop
```
* Защита от DNS Amplification атак: жесткий DROP на 53 порту со стороны WAN-интерфейса.
